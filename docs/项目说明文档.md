> **课程**：Web 开发技术 · 小组作业（对应课程"项目需求文档三：图书/电影数据分析看板"，选题为**电影**方向）

## 一、选题背景

豆瓣电影蕴含海量用户评价数据（评分、评价人数、类型、制片地区、上映年份等），是练习"多维度数据分析 + 可视化呈现"的优质公开数据集。本项目以 **2050 部真实豆瓣电影**为数据基础，构建一个**数据洞察看板（Dashboard）**，帮助用户从评分分布、年度趋势、类型对比、地区口碑、档期与导演等多个视角发现优质作品、了解类型与年代趋势。

项目严格遵循课程技术规范：**数据必须入库、由后端查询返回，不可前端直读静态文件**——这是本课程的核心技术考核点。

## 三、功能模块介绍

看板共 **6 大页面**，采用"左侧多级菜单 + 右侧内容区按页切换"的 B 站风格布局（不做长页滚动）：

### 1. 首页（数据总览）
- **全局筛选面板**：类型下拉、年份区间、评分区间（快捷 + 自定义）、一键重置。筛选条件**全局生效**，同步驱动首页图表与影片库。
- **4 个 KPI 指标卡**：电影总数、平均评分、年代跨度、国家/地区数，随筛选实时刷新。
- **F5 评分分布**柱状图、**F6 年度趋势**折线图。
- **F7 综合热榜速览**：评分最高 5 部影片。

### 2. 热度排行模块（4 页）
- **综合热榜**：热门 TOP10 横向柱状图 + 豆瓣式影片卡片列表（封面 / 评分 / 导演 / 主演 / 梗概），支持按评分 / 按评价人数切换排序。
- **分地区热榜**：中国大陆 / 中国香港 / 中国台湾 / 美国 / 日本 / 韩国 / 英国 / 法国 / 德国等地区 Tab 切换。
- **分年代热榜**、**分类型热榜**：按对应维度浏览高分热门影片。

### 3. 数据洞察模块（2 页）
- **类型对比（F8）**：各类型"平均评分"与"平均热度（评价人数）"双轴柱状图，可切换为**三维雷达图**（评分 / 数量 / 热度），支持图例点击显隐、点击柱体反选类型筛选。
- **深度分析**：
  - **评分 × 热度散点图**：横轴豆瓣评分、纵轴评价人数（对数轴）、气泡大小映射热度，按制片地区着色，每点可点击查看详情；
  - **地区 × 类型热力矩阵**：10 核心地区 × 12 核心类型，颜色 = 平均评分，含合拍片拆分计数。

### 4. 影片库（F9）
- 卡片网格 / 数据表格**双视图切换**。
- 多条件筛选：类型、年份区间、评分区间、关键词搜索；每页 10 条分页。
- 表格列：**封面 → ID → 标题 → 导演 → 类型 → 评分 → 评价人数 → 年份**。
- 点击任意影片打开**详情弹窗**（大图海报 + 完整信息 + 豆瓣条目链接）。

### 5. 全局能力
- **明暗主题切换**（顶栏按钮，全站图表同步重绘）。
- **顶栏全局搜索**：回车跳转影片库并按标题筛选。
- **海报代理**：后端代理豆瓣 CDN 图片（规避防盗链），MD5 缓存。
- **请求层**：防抖、AbortController 超时、并发请求取消、localStorage 缓存。

## 四、技术选型

| 层 | 技术 | 说明 |
|----|------|------|
| 前端 | 原生 HTML + CSS + JavaScript（ES6+） | 无框架、无构建工具，直接运行 |
| 图表 | Apache ECharts 5 | 本地化发行（`frontend/dist/vendor/echarts.min.js`），断网可用，缺失时自动回退 CDN |
| 通信 | 原生 `fetch` | 统一封装（query 拼接 / 业务码校验 / 超时 / 去重取消 / 缓存） |
| 后端 | Spring Boot 3.2.5 + JDK 17 | 分层架构 Controller / Service / Repository |
| ORM | Spring Data JPA（Hibernate） | 实体与 DTO 分离 |
| 数据库 | MySQL 8.0 | 2050 条真实数据 |
| 数据导入 | OpenCSV + DataInitializer | 启动检测空表时从 `classpath:data/movies.csv` 自动入库 |
| API 文档 | SpringDoc OpenAPI（Swagger UI） | 访问 `/swagger-ui.html` 自动生成、可在线调试 |
| 反向代理 | Nginx | 托管前端静态资源（8083）+ 将 `/api` 代理到后端（8081），同源避跨域 |

**数据模型（3 张表）**：`movies`（影片主表）、`genres`（类型字典）、`movie_genres`（影片-类型多对多关联）。一部电影可关联多个类型，多条件筛选采用 **AND 语义**（影片类型集须包含所有选中类型）。

## 五、数据说明

- **来源**：Kaggle 公开数据集 [Douban Movies Dataset](https://www.kaggle.com/dengfuping/douban-movies-dataset)（CC0 公有领域），本项目不写爬虫、不访问豆瓣网站。
- **规模**：原始 2065 条 → 清洗后 **2050 条**有效记录；覆盖 **1931–2026** 年。
- **真实性**：评分、评价人数、简介、海报 URL 均与豆瓣一致，主键使用豆瓣条目 subject id（可溯源）；公开数据集无真实票房数据，故不做"成本-票房"类统计，散点图改为"评分 × 热度"。
- **清洗**（`scripts/build_dataset.py`）：去重、剔除无效记录、从豆瓣链接提取主键、片长/档期标准化；类型维度标准化为 **12 个核心类型**（剧情 / 爱情 / 喜剧 / 恐怖 / 悬疑 / 战争 / 历史 / 纪录片 / 动作 / 动画 / 奇幻 / 科幻），地区聚焦 **10 个核心制片地区**（中国大陆 / 中国台湾 / 中国香港 / 美国 / 日本 / 韩国 / 英国 / 法国 / 德国 / 俄罗斯）。
- **导入**：后端启动时 `DataInitializer` 检测到 `movies` 表为空即自动写入 MySQL（约数秒），控制台打印加载结果。
- **海报**：豆瓣 CDN 有 Referer 防盗链，前端直连会 418；由后端 `GET /api/works/{id}/poster` 携带 Referer 代理拉取并缓存，前端同源引用。

## 六、后端接口一览

统一返回结构：`{ "code": 0, "message": "ok", "data": ... }`（`code=0` 成功）。完整在线文档见 Swagger UI（`http://localhost:8081/swagger-ui.html`）。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/types` | 核心类型列表（A1） |
| GET | `/api/works` | 影片分页 + 多条件筛选（type/yearStart/yearEnd/ratingMin/ratingMax/title）（A2） |
| GET | `/api/works/{id}` | 影片详情（A3） |
| GET | `/api/works/stats` | 评分分布 / 年度趋势 / 类型对比三类统计（A4） |
| GET | `/api/works/top` | 热门 TOP N，支持 country/year/type 维度（A5） |
| GET | `/api/works/{id}/poster` | 海报图片代理（`?size=small\|large`） |
| GET | `/api/movies`、`/api/movies/{id}`、`/api/movies/filters` | 影片查询与筛选项 |
| GET | `/api/stats/overview` | 看板聚合接口（一次返回 KPI + 全部图表数据） |
| GET | `/api/stats/year-trend`、`/genre-compare`、`/rating-votes-scatter`、`/heatmap`、`/season-analysis`、`/top-directors` | 各类统计图表数据源 |

## 七、项目亮点

1. **真实数据、全栈贯通**：2050 条真实豆瓣数据入库 MySQL，后端分层查询，前端 fetch 消费，严格满足课程"数据不可静态读取"的考核点。
2. **筛选全链路联动**：全局筛选状态单一数据源，类型 / 年份 / 评分任一变化即重新请求后端，首页图表、KPI、热榜、影片库同步刷新，图表与列表结果始终一致。
3. **图表点击反选筛选**：评分分布点柱、类型对比点柱/雷达可反向写入筛选条件，实现"看图即筛选"的探索式交互。
4. **体验细节**：明暗主题、防抖、请求取消、海报代理与缓存、表格/卡片双视图、空态/错误态友好提示。
5. **工程质量**：Conventional Commits、分层架构、统一返回与全局异常处理、Swagger 自动接口文档、前端交互回归测试（`scripts/dom-interaction-test.js`、`frontend-smoke-test.js`）。

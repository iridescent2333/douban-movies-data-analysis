# 功能使用手册

> **项目名称**：豆瓣电影数据洞察看板
> **适用对象**：体验 / 验收 / 答辩演示
> **访问地址**：`http://localhost:8083/`（启动方式见《部署与运行说明》）

看板采用"左侧多级菜单 + 右侧内容按页切换"布局，共 6 大页面。左侧菜单四组：**首页**、**热度排行**（综合 / 分地区 / 分年代 / 分类型）、**数据洞察**（类型对比 / 深度分析）、**影片库**。顶栏提供**全局搜索框**与**明暗主题切换**按钮。

---

## 一、首页（数据总览）

**布局**：左侧筛选面板 + 右侧 KPI 卡、双图表、热榜速览。

### 1.1 全局筛选面板（左上）
| 操作 | 效果 |
|------|------|
| **类型**下拉 | 选择某类型后，全站图表与影片库仅统计该类型影片 |
| **年份区间**（起始年 / 结束年） | 仅统计该年份范围内的影片 |
| **评分区间** | 可用快捷下拉（8 分以上 / 7–8 / 6–7 / 6 分以下），也可自定义最低 / 最高分 |
| **重置筛选** | 一键清空所有条件，恢复全量数据 |

> 筛选条件**全局生效**：首页图表、KPI、影片库表格会同步刷新，反之在影片库修改筛选也会影响首页。

### 1.2 KPI 指标卡
- **电影总数**：当前筛选下的影片数量；
- **平均评分**：按影片数加权的平均分；
- **年代跨度**：覆盖的最早–最晚上映年份；
- **国家/地区**：覆盖的制片地区数量。
- 四个指标随筛选实时变化。

### 1.3 F5 评分分布（柱状图）
- 展示各评分段的影片数量；**点击某个柱体**即可按该评分段反选筛选（如点"8.0–8.5"柱 → 自动写入该区间）。

### 1.4 F6 年度趋势（折线 + 柱状双轴）
- 折线为各年份平均评分，背景柱为当年影片数，观察口碑与产量的年代变迁。

### 1.5 F7 综合热榜速览
- 展示评分最高的 5 部影片；点击"查看完整榜单 ›"跳转综合热榜页。

## 二、热度排行模块

### 2.1 综合热榜
- **F7 热门 TOP10 横向柱状图**：按评价人数（万人）排名；
- 右上角切换排序依据：**按评分 / 按评价人数**；
- 下方为豆瓣式影片卡片列表（封面、评分徽章、年份、导演、主演、梗概），**点击卡片**打开详情弹窗。

### 2.2 分地区热榜
- 顶部地区 Tab：**中国大陆 / 中国香港 / 中国台湾 / 美国 / 日本 / 韩国 / 英国 / 法国 / 德国**等，点击切换查看对应地区的高分热门影片。

### 2.3 分年代热榜
- 按年代区间（如 1980 以前、1980s、1990s … 2020 至今）浏览影片。

### 2.4 分类型热榜
- 按影片类型浏览该类型下的高分热门影片。

## 三、数据洞察模块

### 3.1 类型对比（F8）
- **柱状图视图**：双 Y 轴对比各类型的**平均评分**（左轴）与**平均热度·评价人数（万人）**（右轴）；
- **雷达图视图**：右上角切换，以**平均评分 / 影片数量 / 平均热度**三维度对比各类型；
- **交互**：图例可点击显隐；**点击柱体或雷达顶点**可按该类型反选筛选。

### 3.2 深度分析
- **评分 × 热度散点图**：横轴豆瓣评分、纵轴评价人数（对数轴）、气泡大小映射热度；按制片地区着色（见图例）；**点击气泡**查看该影片详情。
- **地区 × 类型 热力矩阵**：行为 10 个核心地区、列为 12 个核心类型，**颜色越暖评分越高**；每格标注平均评分，**悬浮**显示"地区 · 类型 / 平均评分 / 影片数"。
- 下方还有**档期 × 类型**气泡图与**导演 TOP N**柱状图（滚动到可视区域自动加载）。

## 四、影片库（F9）

- **双视图切换**（右上角）：**表格** / **卡片**。
- **筛选条**：类型下拉、年份区间、评分区间、关键词搜索（标题）、重置。与首页筛选共用同一套全局状态。
- **表格视图**列顺序：**封面 → ID → 标题 → 导演 → 类型 → 评分 → 评价人数 → 年份**；每页 10 条。
- **卡片视图**：海报网格，含评分徽章与影片信息。
- **分页**：底部"上一页 / 下一页"与页码指示；第一页 / 最后一页按钮自动禁用。
- **详情**：点击任意行 / 卡片，弹出详情模态框（大图海报、完整信息、豆瓣条目链接）；可通过关闭按钮 / ESC / 点击遮罩关闭。

## 五、全局功能

| 功能 | 操作 | 说明 |
|------|------|------|
| 主题切换 | 顶栏 🌙 按钮 | 明 / 暗主题切换，全站图表同步重绘 |
| 全局搜索 | 顶栏搜索框输入片名后回车 | 自动跳转影片库并按标题筛选 |
| 页面切换 | 左侧菜单 | 按页切换，无长页滚动 |
| 图表联动筛选 | 点击评分分布柱 / 类型对比柱 | 反向写入筛选条件并全局刷新 |

## 六、演示建议路径（答辩用）

1. 首页：改"类型=科幻"→ 观察 KPI、评分分布、年度趋势、热榜同步变化；
2. 点评分分布某柱 → 观察筛选被反选、影片库联动；
3. 热度排行 → 综合热榜 → 切换"按评分 / 按评价人数"；
4. 数据洞察 → 类型对比 → 切换雷达图 → 点某类型柱反选；
5. 数据洞察 → 深度分析 → 散点图点击气泡看详情、热力矩阵悬浮看数据；
6. 影片库 → 表格/卡片切换 → 组合筛选 → 翻页 → 点开详情弹窗；
7. 顶栏切换暗色主题，展示全站换肤。

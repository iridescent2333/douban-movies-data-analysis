## 1. 四阶段开发路线图（已完成复盘）

> 按实际开发顺序整理，括号内为实际偏离初期计划之处。

### 🟦 阶段 1：骨架

目标：前后端能跑起来，前端有静态框架，数据库有表有数据。

```
后端
├── Spring Initializr 生成 pom.xml，选 Boot 3.2.5 + Java 17
│   ├── 依赖：web / data-jpa / validation / mysql-connector / opencsv
│   │   （初期用过 H2 + springdoc + lombok，迁移 MySQL 时已全部移除）
│   └── application.yml：端口 8081、数据源、JPA ddl-auto: update
├── schema.sql：4 张表 CREATE TABLE IF NOT EXISTS
├── Entity：Movie（@ManyToMany）/ MovieFinancial（@OneToOne @MapsId）/ Genre
│   （未使用 Lombok，手写 getter/setter，规避 JDK 兼容问题）
└── Repository：MovieRepository / MovieFinancialRepository / GenreRepository

前端
└── index.html 静态骨架 + style.css 明暗双主题 + ECharts CDN

数据
└── generate_data.py：种子 42、850 条、正态评分 + 类型/国家/档期偏置
```

### 🟦 阶段 2：核心

目标：9 个 API 全部通，前端 8 张图表全部渲染。

```
后端
├── DTO 层：10 个 DTO（MovieDTO / MovieDetailDTO / MovieQueryDTO / FilterOptionsDTO / 6 个统计 DTO）
├── Result<T> + GlobalExceptionHandler：统一返回格式
├── MovieService：getMovies（Pageable + 多条件）/ getById（详情 + 合并财务）/ getFilterOptions
├── StatsService：6 个统计方法（内存分组聚合 + filterMovies 复用筛选）
├── MovieController：list / detail / filters（3 个接口）
└── StatsController：6 个统计接口

前端
├── utils 三件套：config.js / debounce.js / api.js（fetch 封装 + 8s 超时 + 缓存）
├── 8 个 ECharts 图表独立 .js 文件，挂 window.Charts
│   ├── yearTrend（数量柱 + 评分折线双 Y 轴，点击柱子可按年份筛选）
│   ├── genreCompare（横向双柱：评分×1000 + 平均票房）
│   ├── scatterCostBox（气泡散点，size=评分）
│   ├── heatmap（国家 × 类型 热力矩阵）
│   ├── seasonAnalysis（档期 × 类型气泡）
│   ├── topDirectors（导演 TOP N 横向柱状）
│   ├── costBenefit（前端二次加工，基于 scatter 原始数据按预算分桶算 ROI）
│   └── regionCulture（前端二次加工，heatmap + genreCompare 拼三层桑基图）
└── main.js 入口：拉 filters → 渲染筛选控件 → 并发拉 7 个接口 → 渲染图表与列表
```

### 🟦 阶段 3：联调

目标：筛选联动、主题切换、详情弹窗、分页全部打通。

```
├── main.js 筛选联动：控件 change → debounce 300ms → reloadAll()
├── reloadAll()：Promise.all 并发 movies(size=1,供KPI) + 6 个 stats
├── 数据转换层：transformYearTrend / transformScatter / transformHeatmap / transformSeason
├── KPI 计算：renderKPIs(moviesPage, yearTrendRaw, heatmapRaw)
├── 电影列表：Page<MovieDTO> → 卡片 grid + 分页（页码 1-based，传参 -1）
├── 详情弹窗：点击卡片 → GET /movies/{id} → 模态框（海报占位 + 类型标签 + 财务）
├── 主题切换：body.dark → 所有 chart.dispose() + echarts.init(theme) 重绘
└── 异常测试：关后端刷新前端 → Toast 友好提示；不存在的 id → 404 文案
```

### 🟦 阶段 4：迁移与交付（H2 → MySQL + Nginx + ApiFox）

目标：从"能跑的原型"变成"工程交付版"。

```
├── pom.xml：移除 h2 / springdoc-openapi / lombok，引入 mysql-connector-j 8.3
├── application.yml：MySQL 数据源，账号密码全部环境变量化（${DB_USERNAME} 等）
├── DataInitializer：从 classpath CSV 经 JPA 入库（替代 data.sql 直读）
│   └── 修复 detached 问题：save 返回值接回 + flush 后 merge
├── 部署：Nginx 1.26.2 托管 frontend/dist，/api/ 反代 8081（同源无跨域）
├── 接口文档：Swagger UI → ApiFox（docs/apifox-import.json，OpenAPI 3.0）
├── config.js：API_BASE 改空串走 Nginx 代理（不再直连 8080）
├── 隐私：姓名脱敏（姓氏+星号）、凭据文件 gitignore、真实密码零入库
└── 文档：README + docs/ 全套（本目录）
```

### 关键数据流转

```
generate_data.py（种子 42）
    │
    ▼
scripts/movies.csv ──复制──► backend/.../resources/data/movies.csv
    │                              （classpath 内，随仓库分发）
    ▼
DataInitializer（首次启动，表为空时）
    │
    ▼
MySQL movie_dashboard（movies / genres / movie_genres / movie_financials）
    │
    ▼
JPA Repository → Service（Entity→DTO + 统计聚合）→ Controller（Result<T> 包装）
    │
    ▼
Nginx /api/ 反向代理（同源，无跨域）
    │
    ▼
api.js（fetch + 8s 超时 + code 校验 + localStorage 缓存 5 分钟）
    │
    ▼
main.js 数据转换层 → Charts.*.render() / KPI / 列表 / 弹窗
```

## 3. 关键扩展点（加功能按下图索骥）

### 3.1 加"推荐算法"功能

```
[后端]
  ① schema.sql — 加 users / user_ratings 两张表
  ② entity/ — 加 User.java / UserRating.java
  ③ repository/ — 加 UserRepository / UserRatingRepository
  ④ service/ — 加 RecommendService（协同过滤：余弦相似度；或基于内容：类型+国家+评分相近）
  ⑤ controller/ — GET /api/recommend/{movieId}

[前端]
  ① 详情模态框底部加"相关推荐"区块
  ② main.js 打开详情弹窗时并行拉 /recommend/{id}
```

### 3.2 加"实时票房"功能

```
[后端] ① @Scheduled 定时任务 ② MovieBoxOfficeUpdater 调外部 API 更新 box_office_wan
[前端] ① header 加实时票房气泡 ② scatterCostBox 加"实时刷新"按钮 + setInterval
```

### 3.3 加"用户登录"功能

```
[后端] ① Spring Security + JWT ② UserDetailsService 读 users 表 ③ JWT 工具类
       ④ SecurityConfig 放行 /api/auth/** ⑤ AuthController：login / register
[前端] ① 登录模态框 ② api.js 请求头带 Authorization: Bearer <token> ③ 401 拦截跳登录
```

### 3.4 加"评论"功能

```
[后端] ① schema.sql 加 comments 表 ② entity/repository/service/controller 标准 CRUD
[前端] ① 详情弹窗底部加评论区 ② 可选 WebSocket 实时推送
```

### 3.5 导演 TOP N 接入筛选联动（当前最小待办）

```
现状：reloadAll() 里 top-directors 只传 n=20，不随筛选条件变化（后端接口已支持全部筛选参数）
改法：main.js 中把该请求的第二个参数从 { n: CONFIG.TOP_N } 改为 Object.assign({ n: CONFIG.TOP_N }, params)
验证：筛选"2015-2025 + 科幻"后，导演榜应只剩该范围内的导演
```

### 3.6 前端图表加"导出 PNG"

```
不用改后端，ECharts 自带：
const url = chart.getDataURL({ type: 'png', pixelRatio: 2, backgroundColor: '#fff' });
const a = document.createElement('a');
a.href = url; a.download = `chart-${chartId}.png`; a.click();
```

### 3.7 加"电影收藏"功能（localStorage 版，无需后端）

```
① 电影卡片加 ♡ 收藏按钮 ② localStorage 存 id 列表 ③ "只看收藏" checkbox 过滤列表
④ 详情弹窗内收藏状态与列表同步
```

## 4. 项目文件依赖关系

```
pom.xml
  └── application.yml（启动类读取；数据源/端口/JPA）
      ├── schema.sql（Hibernate ddl-auto: update 自动建表的参照）
      └── data/movies.csv（DataInitializer 首次启动加载）

MovieDashboardApplication.java
  ├── CorsConfig.java              ← 直连调试兜底（生产走 Nginx 同源）
  └── DataInitializer.java         ← CommandLineRunner，CSV → MySQL

MovieController.java
  └── MovieService.java
      ├── MovieRepository.java          ← 多条件 JPQL + 分页
      ├── MovieFinancialRepository.java ← 详情合并财务
      └── GenreRepository.java          ← 筛选选项 / 详情类型列表

StatsController.java
  └── StatsService.java
      └── MovieRepository.java          ← filterMovies 复用筛选逻辑

前端（index.html 按此顺序引入）：
  config.js → utils/debounce.js → utils/api.js → utils/ui.js
  → charts/yearTrend.js → genreCompare → scatterCostBox → heatmap
  → seasonAnalysis → topDirectors → costBenefit → regionCulture → main.js

  main.js 调用链：
    DOMContentLoaded
    ├── API.getWithCache('/api/movies/filters')  → 渲染筛选控件
    ├── reloadAll()
    │   ├── Promise.all: movies(size=1) + 6 个 stats
    │   ├── renderKPIs(...)  → 4 个 KPI 卡
    │   ├── Charts.yearTrend / genreCompare / scatterCostBox / heatmap /
    │   │   seasonAnalysis / topDirectors .render(...)
    │   ├── Charts.costBenefit.render(scatterData)        ← 前端二次加工
    │   ├── Charts.regionCulture.render(heatmapData)      ← 前端二次加工
    │   └── loadMovieList()  → 卡片 grid + 分页
    └── 事件绑定：筛选 change(debounce 300ms) / 分页 / Tab / 主题 / resize / 图表点击年份
```

# 项目逻辑流程

> 给谁看的：组员理解整体架构 + 老师看开发路线图和扩展思路  
> 阅读指引：**先看"4 阶段开发路线图"回顾整个项目怎么走下来的，再看"时序图"理解一次完整的前后端交互，最后看"关键扩展点"了解哪些地方可以加功能**。

## 一、4 阶段开发路线图

### 🟦 阶段 1：骨架（~3 天）

目标：前后端能跑起来，Swagger UI 能打开，前端有静态 HTML 框架。

```
第 1 天
├── 后端：Spring Initializr 生成 pom.xml，选 Boot 3.2.5 + Java 17
│   ├── 加依赖：JPA / H2 / springdoc / lombok
│   ├── 写 application.yml（端口、H2 文件模式、Swagger 路径）
│   └── 写 CorsConfig（允许前端跨域）
└── 前端：写 index.html 静态骨架
    ├── header / 筛选条 / KPI 区 / 图表占位 / 列表区 / 模态框
    └── 引入 ECharts CDN

第 2 天
├── 后端：建表 + Entity + Repository
│   ├── 写 schema.sql（4 张表 CREATE TABLE IF NOT EXISTS）
│   ├── 写 3 个 Entity（Movie / MovieFinancial / Genre）
│   └── 写 3 个 Repository 接口
├── 前端：写 style.css 基础样式
│   ├── Flex + Grid 布局
│   └── CSS 变量明暗两套色板
└── Python：写 generate_data.py 初版（种子 + 850 条 + 真实电影名单）

第 3 天
├── Python：补全生成规则（正态评分、类型偏置、档期、财务）+ 写 init_h2_sql.py
├── 后端：跑 data.sql 成功，Swagger UI 能打开但暂无真实接口
└── 验证：`mvnw spring-boot:run` 控制台无红错；`http://localhost:8081/api/movies/filters` 返回 `code:0`
```

### 🟦 阶段 2：核心（~4 天）

目标：9 个 API 全部通，前端 8 张图表全部渲染。

```
第 4–5 天：后端 API
├── DTO 层：10 个 DTO（MovieDTO / MovieDetailDTO / MovieQueryDTO / FilterOptionsDTO / 6 个统计 DTO）
├── Result<T> + GlobalExceptionHandler：统一返回格式
├── MovieService：getMovies（Pageable + 多条件）/ getById（详情 + 合并财务）/ getFilterOptions
├── StatsService：6 个统计方法（JPQL GROUP BY + AVG + COUNT）
├── MovieController：list / detail / filters（3 个接口）
└── StatsController：6 个统计接口

第 6–7 天：前端图表
├── utils 三件套：config.js / debounce.js / api.js（fetch 封装）
├── 8 个 ECharts 图表独立 .js 文件
│   ├── yearTrend（双 Y 轴折线）
│   ├── genreCompare（柱状 + 雷达切换）
│   ├── scatterCostBox（气泡散点，size=评分）
│   ├── heatmap（二维热力矩阵）
│   ├── seasonAnalysis（档期气泡 + 评分颜色映射）
│   ├── topDirectors（横向柱状）
│   ├── costBenefit（前端二次加工，基于 scatter 原始数据）
│   └── regionCulture（前端二次加工，桑基图三层拼接）
└── main.js 入口：DOMContentLoaded → 拉 filters → 渲染筛选控件 → 拉所有 stats → 渲染图表
```

### 🟦 阶段 3：联调（~2 天）

目标：筛选联动、主题切换、详情弹窗、分页全部打通。

```
第 8 天
├── main.js 加筛选联动：每个筛选控件 change → debounce(500ms) → 重新拉 /movies + 所有 stats
├── 主入口调度：写一个 renderAll() 函数
├── 电影列表：Page<MovieDTO> → 渲染卡片 grid + 分页按钮
└── 详情弹窗：点击卡片 → GET /movies/{id} → 渲染模态框（海报占位 + 类型标签 + 财务）

第 9 天
├── 主题切换：toggleTheme() → body 加/去 dark 类 → 所有 chart.dispose() + 重新 echarts.init()
├── Toast 错误提示：fetch 失败 / res.code !== 0 时 showToast
├── 重置按钮：清空所有筛选条件 → 重新拉数据
└── 异常测试：关掉后端刷新前端、用不存在的 movieId 请求
```

### 🟦 阶段 4：答辩（~1 天）

目标：跑通 + 截图 + 彩排 + 文档。

```
第 10 天
├── 完整端到端走一遍：后端启动 → Swagger 试 3 个接口 → 前端打开 → 筛选 → 图表 → 详情
├── 截图 4 张（看板整体 / 筛选联动 / 详情弹窗 / Swagger UI）
├── 录屏 10 分钟完整流程（OBS）
├── 所有文档补齐（本 docs/ 目录下 6 份）
└── 彩排 2 次：控制在 8–10 分钟，高频问题能脱口而出
```

## 二、前后端交互时序图

以下是"用户改了筛选条件后，所有东西联动刷新"这一完整流程的时序：

```
浏览器 (HTML/CSS/JS)    Spring Boot Controller    Service Layer    JPA Repository    H2 Database
       │                        │                        │                  │                 │
       │  ① 用户在筛选条上        │                        │                  │                 │
       │     改了年份范围          │                        │                  │                 │
       │  (change 事件触发)       │                        │                  │                 │
       │                        │                        │                  │                 │
       │  ② debounce(500ms)      │                        │                  │                 │
       │     等待用户停止          │                        │                  │                 │
       │                        │                        │                  │                 │
       │  ③ fetch 并行发 3 组请求  │                        │                  │                 │
       │  ├─ GET /api/movies     │                        │                  │                 │
       │  │  (带全部筛选参数)     │                        │                  │                 │
       │  │──────────────────►   │                        │                  │                 │
       │  │                        │ MovieService           │                  │                 │
       │  │                        │ .getMovies(q)          │                  │                 │
       │  │                        │─────────────────────►│                  │                 │
       │  │                        │                        │ MovieRepository  │                 │
       │  │                        │                        │ .findAll(        │                 │
       │  │                        │                        │   PageRequest +  │                 │
       │  │                        │                        │   Specifications)│                 │
       │  │                        │                        │─────────────────►│                 │
       │  │                        │                        │                  │  SELECT ...     │
       │  │                        │                        │                  │  WHERE year BETWEEN ...
       │  │                        │                        │                  │  AND country = ...
       │  │                        │                        │                  │  ORDER BY rating DESC
       │  │                        │                        │                  │  LIMIT 0, 20
       │  │                        │                        │                  │◄────────────────│
       │  │                        │                        │    Page<Movie>   │                 │
       │  │                        │                        │◄─────────────────│                 │
       │  │                        │ MovieDTO 组装           │                  │                 │
       │  │                        │ (Entity → DTO 列表)    │                  │                 │
       │  │                        │◄─────────────────────│                  │                 │
       │  │                        │ Result.ok(page)        │                  │                 │
       │  │◄──────────────────   │                        │                  │                 │
       │  │                        │                        │                  │                 │
       │  ├─ GET /api/stats/*    │ (6 个并行)              │                  │                 │
       │  │──────────────────►   │                        │                  │                 │
       │  │                        │ StatsService           │                  │                 │
       │  │                        │ .yearTrend()           │                  │                 │
       │  │                        │─────────────────────►│                  │                 │
       │  │                        │                        │ SELECT year,    │                 │
       │  │                        │                        │ AVG(rating),    │                 │
       │  │                        │                        │ COUNT(*)        │                 │
       │  │                        │                        │ FROM movies     │                 │
       │  │                        │                        │ GROUP BY year   │                 │
       │  │                        │                        │─────────────────►                 │
       │  │                        │                        │                  │◄────────────────│
       │  │                        │ List<YearTrendDTO>    │                  │                 │
       │  │◄──────────────────   │ Result.ok(data)         │                  │                 │
       │  │                        │                        │                  │                 │
       │  ④ 所有 fetch resolve    │                        │                  │                 │
       │                        │                        │                  │                 │
       │  ⑤ 遍历 response.data    │                        │                  │                 │
       │     调每个 ECharts 图表  │                        │                  │                 │
       │     .setOption() 更新   │                        │                  │                 │
       │                        │                        │                  │                 │
       │  ⑥ 电影列表区域          │                        │                  │                 │
       │     清空旧卡片 → 渲染     │                        │                  │                 │
       │     新 Page<MovieDTO>     │                        │                  │                 │
       │                        │                        │                  │                 │
       │  ⑦ 分页按钮              │                        │                  │                 │
       │     根据 totalPages      │                        │                  │                 │
       │     更新 disabled 状态   │                        │                  │                 │
       │                        │                        │                  │                 │
```

### 关键数据流转

```
数据源头：movies.csv / data.sql
    │
    ▼
JPA Repository 读 H2
    │
    ▼
Service 层：Entity → DTO 转换 + 统计聚合
    │
    ▼
Controller：封装 Result<T>
    │
    ▼
Spring Boot Jackson 序列化 → JSON
    │
    ▼
HTTP 响应（CORS 放行）
    │
    ▼
前端 fetchJSON() 解析 JSON
    │
    ▼
api.js 返回 Promise<APIResponse<T>>
    │
    ▼
main.js / 各图表 render() 消费数据
    │
    ▼
ECharts.setOption() + 原生 DOM innerHTML 渲染
    │
    ▼
用户看见图表和列表更新
```

## 三、关键扩展点说明

如果答辩时老师问"如果要加 XXX 功能应该改哪"，按下图索回答：

### 3.1 加"推荐算法"功能

```
需要改的地方：

[后端]
  ① schema.sql — 加两张表
     ├── users (id, username, password, ...)
     └── user_ratings (user_id, movie_id, rating)
  
  ② entity/ — 加 User.java / UserRating.java
  
  ③ repository/ — 加 UserRepository / UserRatingRepository
  
  ④ service/ — 加 RecommendService.java
     ├── 协同过滤：余弦相似度找相似用户
     ├── 基于内容：相似类型 + 相似国家 + 相似评分的电影
     └── 热门推荐：评分高 + 评价人数多
  
  ⑤ controller/ — 加 RecommendController
     └── GET /api/recommend/{movieId} → 返回相似电影列表
     
[前端]
  ① 在详情模态框底部加 "相关推荐" 区块
  ② main.js 里详情弹窗打开时并行拉 `/recommend/{id}`
```

### 3.2 加"实时票房"功能

```
需要改的地方：

[后端]
  ① 引入定时任务 @Scheduled
  ② 加一个 MovieBoxOfficeUpdater 组件
     └── 每分钟调用外部 API（如猫眼开放平台）更新 movie_financials.box_office_wan
  ③ 或者：Redis 缓存每日票房快照，前端定时轮询 /api/stats/box-office-live
  
[前端]
  ① 在 header 加一个"实时票房"小气泡，每秒 tick 一下
  ② scatterCostBox 图表加一个 "实时刷新" 按钮 + setInterval 定时器
```

### 3.3 加"用户登录"功能

```
需要改的地方：

[后端]
  ① 引入 Spring Security + JWT
  ② 加 UserDetailsService 实现（从 users 表读用户名密码）
  ③ 加 JWT 工具类：签发 token / 校验 token
  ④ SecurityConfig：哪些接口放行（/api/auth/**）、哪些需要 token
  ⑤ 加 AuthController：POST /api/auth/login / POST /api/auth/register
  
[前端]
  ① 加 login.html 或在首页加登录模态框
  ② api.js 里封装：请求头 `Authorization: Bearer ${localStorage.getItem('token')}`
  ③ 加 401 拦截：token 过期 → 自动跳登录页
```

### 3.4 加"评论/弹幕"功能

```
需要改的地方：

[后端]
  ① schema.sql — 加 comments 表（id, movie_id, user_id, content, create_time）
  ② entity / repository / service / controller 标准 CRUD
  
[前端]
  ① 详情模态框底部加评论区
  ② WebSocket 实现实时推送（新评论自动滚到顶部）
```

### 3.5 把 H2 换成 MySQL（生产环境）

```
只改 2 个文件：

[backend/pom.xml]
  删 h2 依赖，加：
    <dependency>
      <groupId>com.mysql</groupId>
      <artifactId>mysql-connector-j</artifactId>
    </dependency>

[backend/src/main/resources/application.yml]
  datasource:
    url: jdbc:mysql://localhost:3306/movie_db?useSSL=false&serverTimezone=Asia/Shanghai
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: yourpassword
  jpa:
    hibernate:
      ddl-auto: update    # MySQL 第一次启动用 create-drop，之后用 update
    database-platform: org.hibernate.dialect.MySQL8Dialect

H2 特有语法需要改：
  - schema.sql 里的 INT AUTO_INCREMENT MySQL 也支持，基本不用改
  - H2 的 MODE=MySQL 已经让大部分 SQL 兼容
```

### 3.6 前端图表加"导出 PNG"

```
不用改后端！ECharts 自带：

// 每个图表容器加一个"导出"按钮
// 点击时：
const url = chart.getDataURL({
  type: 'png',
  pixelRatio: 2,
  backgroundColor: '#fff'
});
const a = document.createElement('a');
a.href = url;
a.download = `chart-${chartId}.png`;
a.click();
```

### 3.7 加"电影收藏"功能（localStorage 版，无需后端）

```
前端完全自己实现：
  ① movie-grid 渲染卡片时加一个 ♡ 收藏按钮
  ② localStorage.setItem('fav_movies', JSON.stringify([123, 456, ...]))
  ③ main.js 加一个 "只看收藏" checkbox，勾选时从 localStorage 读 id 列表过滤 movieGrid
  ④ 详情模态框里的收藏按钮和列表里的同步
```

## 四、项目文件依赖关系

```
pom.xml
  └── application.yml（被启动类读取）
      └── schema.sql（启动时 DDL）
      └── data/data.sql（启动时 DML）
      
MovieDashboardApplication.java
  ├── CorsConfig.java              ← 配置注入
  ├── OpenApiConfig.java           ← 配置注入
  ├── DataInitializer.java         ← CommandLineRunner 初始 genres
  
MovieController.java
  └── MovieService.java
      ├── MovieRepository.java         ← 直接调用
      ├── MovieFinancialRepository.java ← 合并财务数据
      └── GenreRepository.java          ← 详情返回类型列表

StatsController.java
  └── StatsService.java
      └── MovieRepository.java         ← 所有统计查询

前端：
  config.js → utils/*.js → charts/*.js → main.js
  
  main.js 调用链：
    DOMContentLoaded
    ├── api.getFilters()        → 渲染下拉 + checkbox
    ├── api.getYearTrend()      → charts/yearTrend.render()
    ├── api.getGenreCompare()   → charts/genreCompare.render()
    ├── api.getScatterCostBox() → charts/scatterCostBox.render()
    ├── api.getHeatmap()        → charts/heatmap.render()
    ├── api.getSeasonAnalysis() → charts/seasonAnalysis.render()
    ├── api.getTopDirectors()   → charts/topDirectors.render()
    ├── (前 3 个数据)            → charts/costBenefit.render()      ← 前端二次加工
    ├── (heatmap + genreCompare)→ charts/regionCulture.render()    ← 前端二次加工
    └── api.getMovies()         → 渲染电影列表 grid + 分页
```

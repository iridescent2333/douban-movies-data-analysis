# 部署与运行说明

> **项目名称**：豆瓣电影数据洞察看板
> **适用对象**：首次搭建环境、换机重装、答辩现场部署
> **启动顺序**：**MySQL → 后端（8081）→ Nginx（8083）**，三者缺一不可；浏览器访问 `http://localhost:8083/`。

---

## 一、环境要求

| 软件 | 版本 | 用途 | 备注 |
|------|------|------|------|
| JDK | 17+ | 后端编译运行 | `java -version` 验证 |
| Maven | 3.8+ | 后端构建（或用自带 `mvnw`） | 首次会下载依赖 |
| MySQL Server | 8.0.x | 数据存储 | 记住 root 密码 |
| Nginx | 1.24+ | 前端托管 + API 反向代理 | 二进制不入库，需自行下载解压到**无中文/无空格**路径 |
| Git | 2.x | 版本控制 | 必装 |
| Python | 3.8+ | 仅重新生成数据时需要 | 选装 |
| 现代浏览器 | Chrome / Edge | 访问看板 | 推荐 Chrome |

## 二、本地启动步骤

### Step 0 · 准备数据库（仅首次）

数据为 **2050 条真实豆瓣电影**，已随仓库分发在 `backend/src/main/resources/data/movies.csv`。首次启动后端时 `DataInitializer` 会检测空表并**自动导入**，无需手动导数据。

用 MySQL 客户端执行建库（Hibernate 会自动建表，无需手动建表）：

```sql
CREATE DATABASE IF NOT EXISTS movie_dashboard
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### Step 1 · 配置数据库连接（仅首次，二选一）

```bash
# 方式 A（推荐）：复制模板并填写账号密码
cd backend/src/main/resources
cp application-local.yml.example application-local.yml   # Windows: copy
# 编辑 application-local.yml 里的 password
```

```bash
# 方式 B：环境变量（优先级最高）
export DB_USERNAME=root
export DB_PASSWORD=你的密码
export DB_HOST=localhost DB_PORT=3306 DB_NAME=movie_dashboard
```

> `application-local.yml` 已在 `.gitignore` 中排除，不会入库，各人填各人密码互不影响；全部可配变量见根目录 `.env.example`。

### Step 2 · 启动后端（8081）

```bash
cd backend
mvnw.cmd spring-boot:run        # Windows
./mvnw spring-boot:run          # macOS / Linux
# 或用 IDEA：Open 选 backend 目录 → Run MovieDashboardApplication
```

成功标志（控制台）：

```
Started MovieDashboardApplication in x seconds
  API 基地址 : http://localhost:8081/api
[DataInit] movies 表已有数据 / 加载完成，电影总数: 2050
```

验证接口通：`curl http://localhost:8081/api/works?page=0&size=2`，应返回 `{"code":0,...,"data":{...}}`。

### Step 3 · 配置并启动 Nginx（8083）

1. 下载 Nginx Windows zip 版，解压到无中文路径；
2. 用仓库模板生成配置：复制 `docs/nginx.conf.example` 覆盖 `<nginx>/conf/nginx.conf`，将 `root` 一行的 `__YOUR_FRONTEND_DIST_PATH__` 改成本机 `frontend/dist` 的**绝对路径（正斜杠）**；
3. 关键三处：

```nginx
root   D:/你的路径/movie-dashboard/frontend/dist;   # 本机 frontend/dist 绝对路径
listen 8083;                                         # 团队约定端口（80 常被占用）
location ^~ /api/ { proxy_pass http://127.0.0.1:8081/api/; }   # 与后端端口一致
```

```powershell
cd <你的nginx目录>
.\nginx.exe              # 启动
.\nginx.exe -s reload    # 改配置后重载
.\nginx.exe -s stop      # 停止
```

### Step 4 · 打开看板

浏览器访问 **http://localhost:8083/**（**Ctrl+Shift+R 强刷**避免旧缓存）。看到左侧菜单 + 首页（KPI 卡 + 评分分布 + 年度趋势 + 热榜速览）即成功。

## 四、注意事项

1. **改完前端代码务必 Ctrl+Shift+R 强刷**：Nginx 对 js/css 设了 7 天强缓存（`immutable`），普通刷新可能读到旧文件。
2. **数据更新**：改了 `movies.csv` 后，因 `DataInitializer` 仅在空表时导入，需先清表再重启。仓库提供 `docs/reset-db.sql`：
   ```bash
   mysql movie_dashboard < docs/reset-db.sql   # 清空 movies/genres/movie_genres
   # 然后重启后端自动重导
   ```
3. **换数据集**：下载新版 `douban_all_movies.csv` 放到 `data-source/`，运行
   `python scripts/build_dataset.py --input data-source/douban_all_movies.csv --output backend/src/main/resources/data/movies.csv`，再按上一条重置。
4. **Nginx 不在仓库内**：二进制被 `.gitignore` 排除，clone 后需自行下载解压。
5. **接口在线文档**：后端启动后访问 `http://localhost:8081/swagger-ui.html`（SpringDoc 自动生成）。
6. **离线可用**：ECharts 已本地化到 `frontend/dist/vendor/`，断网也能渲染图表。

## 五、常见问题（FAQ）

| 现象 | 原因 | 解决 |
|------|------|------|
| 后端报 `Access denied for user` | 账号/密码不对 | 检查 `application-local.yml` 或环境变量 `DB_PASSWORD` |
| 后端报 `Unknown database` | 库没建 | 执行 Step 0 建库 SQL |
| 后端报 `Communications link failure` | MySQL 没启动 | Windows：`net start MySQL80` |
| 页面能打开但图表全空 | 后端没起 / 前端缓存 | 先 `curl http://localhost:8081/api/works?page=0&size=1`；再 Ctrl+Shift+R |
| F12 里 `/api/...` 报 502 | Nginx 转发不到后端 | 确认后端在 8081 监听、`proxy_pass` 端口正确 |
| 页面 404 且样式丢失 | nginx `root` 路径不对 | 改成本机 `frontend/dist` 绝对路径（正斜杠）后 `nginx -s reload` |
| Nginx 启动失败 | 8083 被占用 | `netstat -ano \| findstr :8083` 查 PID 并结束，或换 `listen` 端口 |
| IDEA 报 `Port 8081 already in use` | 旧 java 进程未关 | `netstat -ano \| findstr :8081` → `taskkill /F /PID xxx` |
| 改了 CSV 数据没变 | 表非空会跳过导入 | 执行 `docs/reset-db.sql` 后重启后端 |

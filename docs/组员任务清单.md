### 三、工具类 ✅

### 四、图表（8 个，每个独立一个 .js 文件，挂 `window.Charts`）✅

- [x] `yearTrend.js` — 年代趋势（数量柱 + 平均评分折线双 Y 轴；点击柱子派发年份筛选事件）

- [x] `scatterCostBox.js` — 成本票房散点（symbolSize 映射评分）
- [x] `heatmap.js` — 国家 × 类型 热力矩阵（visualMap 色阶）
- [x] `seasonAnalysis.js` — 档期 × 类型气泡图 + 评分颜色映射
- [x] `topDirectors.js` — 导演 TOP N 横向柱状图（label 显示平均评分）
- [x] `costBenefit.js` — 成本区间 × ROI × 评分（组合图，基于 scatter-cost-box 二次加工）
- [x] `regionCulture.js` — 国家 → 类型 → 评分段 桑基图（基于 heatmap + genre-compare 拼接）

### 五、主入口 main.js ✅

- [x] 初始化：DOMContentLoaded → 先拉 `/filters` 渲染筛选下拉和 checkbox
- [x] KPI 卡片：拉 movies(size=1) + year-trend + heatmap 计算 4 个 KPI
- [x] 图表渲染：reloadAll() 中 Promise.all 并发 7 个接口 → 转换层 → 8 个 Charts.*.render()

- [x] 电影列表渲染：Page<MovieDTO> → 卡片 grid + 分页按钮（页码 1-based，传参 -1）
- [x] 点击电影卡片 → 拉 `/movies/{id}` → 渲染详情模态框（海报占位 + 类型标签 + 财务数据）
- [x] 主题切换：body.dark → 所有 chart.dispose() + echarts.init('dark') 重绘

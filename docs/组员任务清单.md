- [x] `seasonAnalysis.js` — 档期气泡图 + 评分颜色映射
- [x] `topDirectors.js` — 导演 TOP N 横向柱状图（导演名 X 轴，作品数 Y 轴，label 显示平均评分）
- [x] `costBenefit.js` — 成本区间 × ROI × 评分（组合图，这个是前端基于 scatter-cost-box 二次加工）
- [x] `regionCulture.js` — 国家 → 类型 → 评分段 桑基图（这个是前端基于 heatmap + genre-compare 拼出来的）

### 五、主入口 main.js

- [x] 初始化：DOMContentLoaded → 先拉 `/filters` 渲染筛选下拉和 checkbox
- [x] KPI 卡片：拉 `/stats/year-trend` 或 `/movies` 全量算 count/avg/rating/yearSpan/countries

- [x] 筛选联动：每个筛选控件 change 时 → debounce 500ms → 重新拉 `/movies`（带上所有参数） + 所有 stats 接口
- [x] 电影列表渲染：根据 Page<MovieDTO> 渲染卡片 grid + 分页按钮

- [x] 主题切换：`document.getElementById('themeToggle').addEventListener('click', toggleTheme)` 里刷新所有图表

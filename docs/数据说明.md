## 一、数据来源方案

### 方案 A（优先）：Kaggle TMDB 公开数据集

`generate_data.py` 启动时会先尝试下载：

```
https://raw.githubusercontent.com/krishnaik06/Movie-Recommender-in-python/master/tmdb_5000_movies.csv
```

有两个镜像 URL 依次尝试。下载成功 → 输出 `scripts/tmdb_raw.csv` → 可以在 `main()` 里扩展解析逻辑（本次作业未启用，保持独立可复现）。

**优点**：5000+ 条真实 TMDB 数据，包含预算/票房/类型；  
**缺点**：字段和我们不完全对齐，需要写复杂的字段映射 + 清洗；网络不一定通。

### 方案 B（fallback，实际使用）：本地高质量模拟数据

Python `random.seed(42)` 保证**每次生成完全一致**，适合课程作业复现和 diff。

生成策略：
1. **电影名**：100 部真实中文 + 100 部真实英文 + 400 部中文造词（前缀×中间×后缀组合） + 250 部英文造词 → 约 850 条
2. **导演 / 演员**：从真实导演池（张艺谋、诺兰、宫崎骏等 70+ 人）和真实演员池（张国荣、小李子等 80+ 人）里随机抽取
3. **类型**：14 种（剧情/喜剧/爱情/动画/科幻/悬疑/恐怖/动作/战争/文艺/主旋律/纪录片/短片/Cult），每部电影选 1–3 种

### 2.4 年份分布（中间重两端轻）

```python
# 权重公式：中间年份概率更高
weights = [1.0 + 0.03 * abs(y - 2010) for y in years]
# 即 2010 年权重最低 1.0，越远权重越高（但增长缓慢）
```

效果：2008–2015 年是峰值区间（每年度 35–45 部），1995 和 2025 年各约 15 部。

### 2.6 财务数据规则

- **预算+票房双全的覆盖率**：约 **50%**（`random.random() < 0.50`，当前 850 条中 **418 条**）
- **入库口径**：`movie_financials` 表共 **850 行**——只要 budget / box_office / release_date 任一非空即由 `DataInitializer` 建行（833 条有上映日期）
- **基础预算**：正态 N(5000 万美元, 4000 万美元)，叠加类型偏置
- **类型预算偏置**：科幻×3.0、动作×2.5、战争×2.2 → 文艺×0.5、短片×0.2
- **华语折扣**：中国大陆/香港/台湾电影预算 × 0.3 ~ 0.7
- **票房倍数**：`0.3 + rating × 0.5`（评分 7 → 约 3.8 倍），正态扰动 ±1.5 倍，clamp 到 [0.3, 12.0]

### 2.7 评价人数（vote_count）

和评分 **log 正相关**：评分越高，评价人数越多，爆款（评分 ≥ 8.5）有 35% 概率指数放大（3–10 倍）。

```python
base = 500 + (rating - 2.0) * 5000   # 评分 7 → base ~ 25500
if rating >= 8.5 and random() < 0.35:
    votes *= random(3, 10)          # 爆款放大
```

## 三、生成规则

| 参数               | 值                 | 说明                                       |
|--------------------|--------------------|--------------------------------------------|
| Python 随机种子    | `random.seed(42)`  | **固定 42**，每次运行结果完全一致          |
| 总条数             | `n=850`            | 脚本入口参数，可改                         |
| CSV 编码           | UTF-8 BOM          | Excel 打开不乱码                           |
| CSV 落点            | `backend/src/main/resources/data/movies.csv` | 随仓库分发，后端启动时经 JPA 入库 |
| 财务覆盖率阈值     | 0.50               | 约一半电影有预算/票房（418/850）           |
| 票房倍数 clamp     | [0.3, 12.0]        | 防止出现 0 或天文数字                      |
| 评分 clamp         | [2.0, 9.8]         | 豆瓣评分实际范围（<2 分不显示，>9.8 罕见） |
| 片长范围           | [70, 185] 分钟     | 正态 N(108, 18) 截断                       |

## 五、数据可扩展性

如果需要：

1. **改成真实数据**：把 Kaggle 下载成功后的 CSV 解析逻辑补上，字段映射 → `pick_country()` 用 TMDB 的 `production_countries[0].name`、类型用 TMDB `genres[].name`
2. **扩大数据量**：只改 `generate_movies(n=XXXX)`，其余逻辑不变
3. **改成中文档期**：seasonTag 字段已经是中文，直接用就行
4. **改成分级数据**：在 movies 表加 rating_level VARCHAR(20) 字段，在 generate_data.py 里按评分区间自动标注（9+ = S 级，8-9 = A 级……）

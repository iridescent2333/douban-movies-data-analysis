# 快速上手：从零到看板跑起来

> 给谁看的：新加入的组员 / 换电脑重装环境的同学
> 阅读指引：**按 Step 0 → 5 顺序做，不要跳步**。预计 30–40 分钟（含 Maven 首次下载依赖）。
> 启动顺序固定为：**MySQL → 后端 → Nginx**，三者缺一不可。

---

## Step 0 · 准备数据库（仅首次）

MySQL Workbench 用自己的账号连接，执行：

```sql
CREATE DATABASE IF NOT EXISTS movie_dashboard
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

> 脚本文件在 `docs/mysql-init.sql`，内容相同。Hibernate 启动时会自动建 4 张表，**不需要手动建表**。

## Step 1 · 配置数据库连接（仅首次，二选一）

```bash
# 方式 A（推荐）：复制模板，填写自己的账号密码
cd backend/src/main/resources
cp application-local.yml.example application-local.yml    # Windows: copy
# 编辑 application-local.yml 里的 password
```

```bash
# 方式 B：设置环境变量（优先级最高）
export DB_USERNAME=root
export DB_PASSWORD=你的密码
export DB_HOST=localhost DB_PORT=3306 DB_NAME=movie_dashboard
# Windows PowerShell：$env:DB_PASSWORD="你的密码"
```

> ⚠️ `application-local.yml` 与 `.env` 已在 `.gitignore` 中排除，**不会进入版本库**，各人填各人的密码，互不影响。
> 全部可配变量见根目录 `.env.example`。

## Step 2 · 启动后端

```bash
cd backend
mvnw.cmd spring-boot:run          # Windows
./mvnw spring-boot:run            # macOS / Linux
# 或 IDEA：File→Open 选 backend 目录（不要选 movie-dashboard 根）→ Run MovieDashboardApplication
```

首次启动会自动完成：Hibernate 建 4 张表 → DataInitializer 从 `classpath:data/movies.csv` 加载 **850 条**电影数据 → 监听 **8081** 端口。

成功标志（控制台）：

```
Started MovieDashboardApplication in x seconds
  API 基地址 : http://localhost:8081/api
[DataInit] 加载完成！ 电影总数: 850  类型: 14  财务记录: 850
```

验证接口通：

```bash
curl http://localhost:8081/api/movies?page=0&size=2
# 应返回 {"code":0,"message":"ok","data":{...}}
```

> 后续重启若表中已有数据会跳过加载。想重新加载：先 `TRUNCATE TABLE movie_dashboard.movies; TRUNCATE TABLE movie_dashboard.movie_financials;` 再重启。

## Step 3 · 配置并启动 Nginx

```bash
# 1. 没有 Nginx 的先去 https://nginx.org/en/download.html 下载 Windows zip 版，解压到无中文路径
# 2. 用仓库模板生成配置：
#    复制 docs/nginx.conf.example 覆盖 <你的nginx>/conf/nginx.conf
#    把 root 一行的 __YOUR_FRONTEND_DIST_PATH__ 改成本项目 frontend/dist 的绝对路径（正斜杠）
```

nginx.conf 关键三处（listen / root / 反向代理）：

```nginx
root D:/你的路径/movie-dashboard/frontend/dist;        # 本机 frontend/dist 绝对路径

location ^~ /api/ {
    proxy_pass http://127.0.0.1:8081/api/;             # 与后端端口 8081 一致
}

listen 8083;   # 团队约定端口（80 常被 IIS/旧 nginx 占用）；访问地址随之变为 http://localhost:8083/
```

```powershell
cd <你的nginx目录>
.\nginx.exe              # 启动
.\nginx.exe -s reload    # 改配置后重载
.\nginx.exe -s stop      # 停止
```

## Step 4 · 打开看板

浏览器访问 **http://localhost:8083/**（Ctrl+Shift+R 强刷避免旧缓存）。

看到：筛选条 + 4 个 KPI 卡 + 4 张核心图表 + Tab 面板 + 电影卡片列表 = 成功。

## Step 5 · ApiFox 调试接口（可选）

ApiFox → 新建项目 → 导入 → OpenAPI/Swagger → 选 `docs/apifox-import.json` → 新建环境，`baseURL` 填 `http://localhost:8083`（走 Nginx）或 `http://localhost:8081`（直连后端）。

## FAQ（按出现频率排序）

| 现象 | 原因 | 解决办法 |
|------|------|---------|
| 后端报 `Access denied for user` | 账号或密码不对 | 检查 `application-local.yml` / 环境变量 `DB_PASSWORD` |
| 后端报 `Unknown database 'movie_dashboard'` | 库没建 | 执行 Step 0 的建库 SQL |
| 后端报 `Communications link failure` | MySQL 服务没启动 | Windows：`net start MySQL80` |
| 组员 clone 后**没有 nginx 目录** | 正常，二进制不入库 | 自行下载 Nginx（见 Step 3） |
| 页面能打开但图表全空 | 后端没起来 / 前端 JS 缓存 | 先 `curl http://localhost:8081/api/movies?page=0&size=1`；再 Ctrl+Shift+R |
| F12 里 `/api/...` 报 **502** | Nginx 转发不到后端 | 确认后端在 8081 监听，检查 `proxy_pass` 端口 |
| 页面 404 且样式全丢 | nginx.conf 的 `root` 路径不对 | 改成本机 `frontend/dist` 绝对路径（正斜杠）后 `nginx.exe -s reload` |
| Nginx 启动失败 | 8083 端口被占用（团队约定端口，原 80 常被 IIS / 旧 nginx 占） | `netstat -ano \| findstr :8083` 查 PID → `taskkill /F /PID xxx`，或再换一个 `listen` 端口并同步本文档 |
| IDEA Run 报 `Port 8081 already in use` | 旧 java 进程没关 | `netstat -ano \| findstr :8081` → `taskkill /F /PID xxx` |
| 改了 CSV 但数据没变 | DataInitializer 表非空会跳过 | TRUNCATE `movies` 与 `movie_financials` 后重启 |
| 筛选后数量没变化 | 前端 localStorage 缓存 5 分钟 | Ctrl+Shift+R 强刷验证 |
| ApiFox 导入失败 | JSON 格式问题 | `python -m json.tool docs/apifox-import.json` 校验 |
| ECharts 加载失败（断网） | CDN 被墙 | 临时挂代理，或把 `echarts.min.js` 下载到本地改 `index.html` 引用 |
